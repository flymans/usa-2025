# USA 2025

Черновой Next.js-каркас интерактивного архива путешествия по США.

## Локальный запуск

```bash
npm install
npm run dev
```

Страница доступна по адресу `http://localhost:3000/usa/`.

## Статическая сборка

```bash
npm run build
```

Готовые файлы появляются в `out/` и рассчитаны на размещение по пути `/usa/`.

Карта строится как inline SVG из геометрии `us-atlas`; демонстрационные точки
позже будут заменены фактическими остановками путешествия.
